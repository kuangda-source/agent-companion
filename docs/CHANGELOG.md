# 开发版更新

## Mac 0.4.13 / 板端保持 0.2.18

- 支持阿里云百炼独立 TTS 配置和 Key，语音生成默认关闭，保存不触发调用；适配器通过本地模拟，实际 TTS 尚未测试。
- Qwen3.8 摘要关闭长思考、追问使用有限思考预算，均不拼接历史私有思考；供应商参数仅用于官方百炼地址。摘要使用原生严格 JSON Schema，约束字段、状态与引用范围；上下文仅包含本批相关项目。
- 增量摘要按最多两个会话分批，优先待答／异常并轮流更新，积压自动续批；逐会话校验／提交，重复主题合并，未通过的会话继续保留增量，保留已有合批、引用校验和每日上限。
- Mac API 设置增加语音服务配置；助手切换先停用再保存新 Key，避免新 Key 被旧地址使用。本次不改板端固件。

## Mac 0.4.12 / 板端保持 0.2.18

- 会话增量先写入本地收件箱，摘要消费位置独立保存；任务、结果、未解决问题按会话维护并保留修订，仅向模型发送受影响会话和有限上下文。
- 加入默认关闭的播报队列：优先级、重复故障周期、待答取消、过期、额度确认和持久化投递；重要简报到语音队列的失败可重试，不撤销记忆。
- Mac 新增“语音播报”准备页及系统 TTS 文件生成。监视器是目标输出端，Mac 不自动发声。分片／播放回执端口通过软件模拟；实际板端播放及 USB／LAN／中转音频适配仍待接入，未刷写新固件。
- Codex 明确输入请求接入等待状态；官方运行状态只读 proxy 可用时补充审批等待，未知场景保持未知。

## Mac 0.4.11 / 板端 0.2.18

- Agent 卡片在额度旁显示对应窗口的重置倒计时，例如“2d04h重置”“1h30m重置”。选择较紧的额度窗口时，倒计时同步取该窗口的期限。
- 沿用来源提供的重置时间，屏幕本地走时，不增加额度查询频率；到期显示“待确认”，连接过期显示“待更新”，不据此推定满额。没有重置时间或显示账户余额时不添加倒计时。

## Mac 0.4.10 / 板端保持 0.2.17

- AI 助手明确区分服务端暂无可用账号、503、限流、超时与连接失败；保留已有简报，显示自动重试时间。
- 连续暂时故障按 5、10、20、40、60 分钟退避，最长每小时重试，重启也保留等待时间。到期后可恢复失败的整理任务，无需等待新消息；新对话仍继续采集，手动更新可立即重试。有效回答或切换接口/模型后清除退避，调用仍受每日上限约束。
- 错误诊断仅保存固定错误码和时间，不保留上游错误正文；模型密钥、地址与已有消息不会因升级被替换。本次无需更新板端固件。

## Mac 0.4.9 / 板端保持 0.2.17

- 修复 Codex 定时任务已暂停、本机旧数据库仍记为启用时，小屏持续显示“等待调度”的问题。读取计划时同时核对本机自动化配置，明确暂停的任务先排除，再按同一对话选择最近的启用计划。
- 数据库读取失败时，上次缓存也会排除明确暂停的任务；不修改 Codex 原始配置或对话。运行中的真实会话仍按原规则优先显示，本次无需重刷板子。

## Mac 0.4.8 / 板端 0.2.17

- 修复 Grok 因实时工作状态不可读、一直落在单帧 unknown 素材而静止的问题。已有多帧中性 idle 素材时，未知状态也播放该循环；状态文字和遥测仍为未知，不触发工作或庆祝动作。
- 原始素材保持不变，不叠加整身位移或呼吸缩放；关闭动画时仍停在首帧。

## Mac 0.4.7 / 板端 0.2.16

- 屏幕“工具 → Wi-Fi 网络”支持本机扫描、选网、屏幕键盘输入密码及保存，不依赖 Mac 或 Gateway 在线。可重连已保存网络，也支持手动输入隐藏网络名称与开放网络；密码不会返回主机，关闭或提交后清空输入框。
- 更换 Wi-Fi 只更新网络凭据，保留已有中转和局域网配对。扫描与连接在后台处理。
- 默认 USB 改为 USB 优先，Mac 的局域网和中转保持可用，避免屏幕外出联网后主机因 USB 模式拒绝无线连接。

## Mac 0.4.6 / 板端保持 0.2.15

- 默认使用 USB，同步进程随 Mac 本机服务启动，自动识别单块 Espressif USB Serial/JTAG 设备，断开后重新检测；无需另开终端运行桥接。自动模式优先 USB，局域网与云中转保留为可选项。
- 连接状态纳入 USB 应用回执，概览及连接页明确显示“USB 已连接”。配网、主题和会话点击沿用现有协议。本次无需重刷板子。

## Mac 0.4.5 / 板端保持 0.2.14

- Grok 额度的本地缓存读取间隔由 10 分钟改为 5 分钟。Bot 消息更新频率和界面展示保持不变，无需重刷板子。

## Mac 0.4.4 / 板端 0.2.14

- Grok 列表改为 Bot 名称、当前状态与最近消息，移除 TIME、IN/OUT、CACHE、CTX 列；可点击展开消息。切换其他 Agent 恢复原有指标和定时倒计时。
- Grok 额度在启动后每 10 分钟读取一次本地缓存，与消息采集分开。连接正常时仅显示剩余额度，不展示更新时间或“上次”前缀；原始缓存时间仍保留在内部数据中。
- Grok 实时状态缺少可靠来源时继续显示未知；不根据消息时间推测运行或完成。

## Mac 0.4.3 / 板端 0.2.13

- Mac 新增 Agent 页，可从 Codex、Grok、DeepSeek、Claude Code 中选择 1–3 个；默认 Codex / Grok / DeepSeek，旧设置自动补充默认选择。
- 小屏、统计和助手整理跟随所选来源；取消选择不会停止原软件任务。共享 LVGL 按实际数量排列卡片。
- Grok Bot 读取本地 Bot 名称与公开消息缓存。实时工作状态、完成事件和 Token 尚不可读，保持未知或空值；每周额度从本地缓存读取并标为上次。
- Grok 使用独立占位资源，后续沿用七态素材接口替换。板端需升级到 0.2.13 以识别新 Agent 与可变数量。

## Mac 0.4.2 / 板端保持 0.2.12

- 增加官方只读额度查询，活动时每分钟核对，空闲且剩余低于 20% 时每小时补查，达到 20% 即停止空闲补查。
- 启动、唤醒、新轮次、结束及预计重置时触发查询，合并重复触发；只以实际返回值确认重置。
- 取消固定 15 分钟时效，保留原始观测与私有缓存。查询失败保留上次值，不推算满额，不影响设备数据通道。
- CLI 查询进程有超时与取消清理；只发送初始化及额度读取请求，不创建模型对话或兑换重置权益。无需更新板端协议。

## Mac 0.4.1 / 7B 固件 0.2.12

- 移除小屏“会话 / 定时”切换按钮。在 Mac“屏幕 → 显示定时任务”统一控制会话列表中的定时条目，偏好会保存并同步到预览与设备。
- 关闭显示不修改原自动化，真实会话仍保留；开启时继续采用运行优先、定时黄色、同一关联对话去重的规则。
- Codex 额度在空闲 15 分钟后保留尚未重置的上次观测并标注“上次”，不再直接变成空值。重置时间已到则移除旧窗口；无重置时间的旧读数不无限保留。空额度事件不会覆盖最后有效记录。
- 保留额度原始观测时间，并在本机来源读取失败时继续执行窗口到期检查。旧协议数据没有 freshness 标记时仍兼容。

验证：80 项 Bun 测试、14 项 Python 合同检查、6 项共享 C/LVGL 回归；原生 Mac 构建签名、rev3_x 固件编译和参考板配网保留/开关两态实屏检查通过。硬件变更需按你自己的板型和芯片版本验证。
